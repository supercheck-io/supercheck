# Support

Thanks for using Supercheck. Here is where to get help.

## Documentation

- Product and app documentation: [supercheck.io/docs/app/welcome](https://supercheck.io/docs/app/welcome)
- CLI documentation: [supercheck.io/docs/cli/commands](https://supercheck.io/docs/cli/commands)
- API reference: [supercheck.io/docs/api](https://supercheck.io/docs/api)
- Recorder documentation: [supercheck.io/docs/recorder](https://supercheck.io/docs/recorder)
- Self-hosting guide: [supercheck.io/docs/app/deployment/self-hosted](https://supercheck.io/docs/app/deployment/self-hosted)

## Questions and ideas

- [GitHub Discussions](https://github.com/supercheck-io/supercheck/discussions) for questions, design ideas, and larger proposals.
- [Discord](https://discord.gg/UVe327CSbm) for real-time community chat.

## Bugs and feature requests

- Search [existing issues](https://github.com/supercheck-io/supercheck/issues) first, then open a new issue using the issue chooser.
- For configuration or deployment help, include your deployment mode (self-hosted or cloud), version, and redacted logs.

## Security

Do not report vulnerabilities in public issues or discussions. Follow [SECURITY.md](SECURITY.md) and use
[private vulnerability reporting](https://github.com/supercheck-io/supercheck/security/advisories/new).

## Commercial support

Supercheck is open source under AGPL-3.0-only. For hosted or commercial support, contact `hello@supercheck.io`.
