# Preset avatars

`notionists-*.svg` are generated with [DiceBear](https://www.dicebear.com) from the
[Notionists](https://heyzoish.gumroad.com/l/notionists) style by Zoish, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The list of presets lives in
`src/lib/avatar-presets.ts`; add a file there when you add one here.
