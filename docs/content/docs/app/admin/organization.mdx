Manage your organization's projects, members, CLI tokens, AI SRE setup, and audit trails from the Admin panel.

## Create and select organizations

Use the organization menu above the project selector to switch organizations or choose **Create organization**. Enter a name of 2–50 characters. Creation adds a default project and makes you the owner. Switching organizations selects an active project in that organization and reloads the app.

In Supercheck Cloud, verify your email before creating an organization. The default ownership limit is five organizations per user; contact support if you need more. Organizations you join by invitation do not count toward your ownership limit.

### Cloud subscriptions

Each organization has its own monthly subscription. If you already own a paid organization and create another, the new organization starts without a subscription. Creating it does not charge you, copy your paid plan, or change the original organization's subscription. The new organization's owner can choose a plan on the subscription page, or use the organization menu there to return to a paid organization.

Members share their organization's included usage and limits. Joining an organization with an active subscription does not require buying a personal subscription. Accepting an invitation selects the invited organization and project. Project permissions still depend on the role and project assignments.

Usage, project and member limits, invoices, and spending controls are separate for each organization. Creating more projects inside one organization uses that organization's existing plan. Only the organization owner can subscribe or open **Manage subscription** to change or cancel the plan.

Self-hosted organizations do not require a cloud subscription. Their execution capacity depends on the infrastructure and concurrency settings you configure.

## Roles

The system uses a 6-role RBAC system with specialized roles for organization and project management.

<Tabs items={['Organization Roles', 'Project Roles']}>
<Tab value="Organization Roles">

| Role | Permissions |
|------|-------------|
| **Super Admin** | System-wide control, user management, and full access to everything. |
| **Org Owner** | Full organization control, including deletion and member management. |
| **Org Admin** | Managing members and organization settings (cannot delete org). |

</Tab>
<Tab value="Project Roles">

| Role | Permissions |
|------|-------------|
| **Project Admin** | Full control of assigned projects (create/edit/delete resources). |
| **Project Editor** | Create and edit resources in assigned projects (cannot delete). |
| **Project Viewer** | Read-only access to all projects in the organization. |

</Tab>
</Tabs>

## Delete an organization

Only the organization owner can request deletion. An organization with projects cannot be deleted through the organization API; contact your administrator or support for data removal. For an organization linked to cloud billing, contact support to close it safely. Deleting app data does not cancel a subscription. Use **Manage subscription** to cancel the plan.

## CLI Tokens

Manage organization-wide and project-scoped CLI tokens for API access and automation.
Tokens created here can be used in your CI/CD pipelines and external integrations.

1. Go to **Admin → CLI Tokens**
2. Click **Create Token**
3. Select the target project and assign an expiry date
4. Copy the generated token securely

## AI SRE Setup

Administrators configure project-level AI SRE setup from **Admin** so responders do not need to manage setup screens during an incident.

The setup tabs are:

- **Services** — Open the top-level **Services** page to register production services and ownership metadata used to map alerts, incidents, and connector evidence.
- **Integrations** — Configure read-only evidence connectors and link alert notification providers to connector context.
- **Diagnostic Recipes** — Save bounded, allowlisted read-only query recipes for common incident questions.
- **Private Agents** — Register outbound-only workers for querying private network tools without opening inbound access.

See [AI SRE setup](/docs/app/admin/ai-sre-setup) for the full setup flow.

## Audit Log

Track all actions performed within your organization. View who did what and when for compliance and security monitoring.

![Audit Log](/screenshots/org-admin-audit-list.png)

### Event Categories

The audit log captures events across these categories:

- **Authentication** — Login, logout, password resets
- **Authorization** — Role changes, permission grants
- **Resource Management** — Test creation, monitor updates, job deletions
- **Execution** — Manual test runs, job triggers
- **Configuration** — Settings changes, integration updates
- **Security** — Failed logins, unauthorized access attempts
