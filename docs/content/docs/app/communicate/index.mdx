## Notification channels

| Channel | Delivery |
|---|---|
| Email | HTML emails via SMTP with status details and dashboard links |
| Slack | The channel set by your Slack webhook |
| Webhook | JSON to a publicly reachable endpoint. Presets cover PagerDuty, Jira Service Management, Splunk On-Call, Better Stack, incident.io and custom integrations |
| Telegram | Bot messages to chats or groups with Markdown formatting |
| Discord | Embedded messages to server channels with color-coded status |
| Microsoft Teams | Adaptive Card notifications via Power Automate workflows |

Failure and recovery thresholds keep brief interruptions quiet. See [Threshold configuration](/docs/app/communicate/alerts#threshold-configuration).

## Status page capabilities

| Capability | Detail |
|---|---|
| **Components** | Individual status tracking with linked monitors |
| **Incidents** | Investigating, Identified, Monitoring, Resolved |
| **Maintenance** | Scheduled planned-downtime updates with their own status |
| **Subscribers** | Email, Slack and webhook updates for incidents and status changes |
| **Branding** | Logos, colors and custom domains |
| **Uptime** | 90-day uptime history |
