Keep your team informed when issues occur and communicate service status to your users. Supercheck provides multi-channel alerting for internal teams and public status pages for external communication.

## Core Features

<Cards>
<Card icon={<Bell className="text-amber-500" />} title="Notifications" href="/docs/app/communicate/alerts">
Get notified via Slack, email, Discord, Telegram, Microsoft Teams, or webhooks when tests fail or monitors go down
</Card>

<Card icon={<Tally4 className="text-emerald-500" />} title="Status Pages" href="/docs/app/communicate/status-pages">
Create public-facing pages to communicate system health, incidents, and maintenance to your users
</Card>
</Cards>

## Alert Providers

Send notifications through multiple channels. Configure different providers for different severity levels or teams.

<Cards>
<Card icon={<Mail className="text-rose-500" />} title="Email">
Professional HTML emails via SMTP with detailed status information and dashboard links
</Card>

<Card icon={<BrandMark name="slack" />} title="Slack">
Send alerts to the channel configured by your Slack webhook.
</Card>

<Card icon={<BrandMark name="webhook" />} title="Webhook">
Send JSON to a publicly reachable endpoint; use templates for PagerDuty, Opsgenie, or custom integrations.
</Card>

<Card icon={<BrandMark name="telegram" />} title="Telegram">
Bot messages to chats or groups with Markdown formatting
</Card>

<Card icon={<BrandMark name="discord" />} title="Discord">
Embedded messages to server channels with color-coded status
</Card>

<Card icon={<BrandMark name="teams" />} title="Microsoft Teams">
Adaptive Card notifications via Power Automate workflows
</Card>
</Cards>

Failure and recovery thresholds keep brief interruptions quiet: see [Threshold configuration](/docs/app/communicate/alerts#threshold-configuration).

## Public Status Pages

| Capability | Detail |
|---|---|
| **Components** | Individual status tracking with linked monitors |
| **Incidents** | Investigating, Identified, Monitoring, Resolved |
| **Maintenance** | Scheduled planned-downtime updates with their own status |
| **Subscribers** | Email, Slack and webhook updates for incidents and status changes |
| **Branding** | Logos, colors and custom domains |
| **Uptime** | 90-day uptime history |
