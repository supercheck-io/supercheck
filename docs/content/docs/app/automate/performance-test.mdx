## Create a performance test

<Steps>
<Step>
Go to **Create → Performance Test**.
</Step>
<Step>
Write a k6 script in the editor and set the load profile (VUs, duration).
</Step>
<Step>
**Run** and analyze the results.
</Step>
</Steps>

<Accordions>
<Accordion title="Worker availability (503 EXECUTION_QUEUE_UNAVAILABLE)" id="worker-availability">

If no worker is available to run k6 tests, the API returns HTTP 503 with code `EXECUTION_QUEUE_UNAVAILABLE`. The same response is returned, without creating a run, while the app cannot reach Redis for more than about two seconds. Retry after the `Retry-After` interval. Self-hosted: make sure a worker is running and has finished starting, or check the Redis (or Sentinel) service and the app's connection settings.
</Accordion>
</Accordions>

## Example script

Start with a smoke test against a system you own or have permission to test, and increase load gradually. Each run uses the load profile in your script, so several tests at once add up. Set an `API_URL` project variable to your test environment and replace `/health` with the endpoint to exercise.

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  stages: [
    { duration: '2m', target: 10 },   // Ramp-up to 10 VUs
    { duration: '5m', target: 50 },   // Increase to 50 VUs
    { duration: '3m', target: 80 },   // Peak load at 80 VUs
    { duration: '2m', target: 0 },    // Ramp-down
  ],
  thresholds: {
    http_req_failed: ['rate<0.02'],              // Error rate < 2%
    http_req_duration: ['p(95)<600', 'p(99)<1200'], // Latency thresholds
    checks: ['rate>0.95'],                       // 95% of checks pass
  },
};

export default function () {
  const baseUrl = getVariable('API_URL');
  const response = http.get(`${baseUrl}/health`);

  check(response, {
    'status is 200': (res) => res.status === 200,
    'request under 600 ms': (res) => res.timings.duration < 600,
  });
  sleep(1);
}
```

## Load profiles

| Profile | Use case |
|---------|----------|
| **Smoke** | 1-2 VUs, 1 min. Verify the script works |
| **Load** | 10-50 VUs, 5-10 min. Normal load |
| **Stress** | 100+ VUs, 10-30 min. Find the breaking point |
| **Spike** | Sudden ramp, 5 min. Handle traffic bursts |

## Thresholds

Set pass/fail criteria:

```javascript
export const options = {
  thresholds: {
    http_req_duration: ['p(95)<500'], // 95% under 500ms
    http_req_failed: ['rate<0.01'],  // Less than 1% errors
  },
};
```

See [k6 thresholds](https://grafana.com/docs/k6/latest/using-k6/thresholds/).

## Use variables

```javascript
import http from 'k6/http';
import { check } from 'k6';
import { SharedArray } from 'k6/data';

// Attach a USERS_CSV file variable with one username per row and a header.
const users = new SharedArray('users', () =>
  open(getFile('USERS_CSV'))
    .split('\n')
    .slice(1)
    .map((line) => line.trim())
    .filter(Boolean)
);

if (users.length === 0) throw new Error('USERS_CSV must contain at least one user');

export default function () {
  const baseUrl = getVariable('API_URL');
  const apiKey = getSecret('API_KEY');
  
  const username = users[__VU % users.length];
  const response = http.get(`${baseUrl}/protected?user=${encodeURIComponent(username)}`, {
    headers: { Authorization: `Bearer ${apiKey}` }
  });
  
  check(response, { 'status is 200': (r) => r.status === 200 });
}
```
