Run SQL queries and validate database state with Playwright-based tests.

## Create a database test

<Steps>
<Step>
Go to **Create → Database Test**.
</Step>
<Step>
Write your SQL query and add assertions.
</Step>
<Step>
**Run** and **Save**.
</Step>
</Steps>

Database connections are defined inline in your script. Use `getVariable()` for host, port, database and user, and `getSecret()` for the password. There is no connection picker in the UI. Import the matching Node driver (`pg`, `mysql2` or `mssql`) at the top of the script.

## Example

```typescript
import { expect, test } from '@playwright/test';
import { Pool } from 'pg';

const pool = new Pool({
  host: getVariable('DB_HOST'),
  port: parseInt(getVariable('DB_PORT') || '5432'),
  database: getVariable('DB_NAME'),
  user: getVariable('DB_USER'),
  password: getSecret('DB_PASSWORD'),
  ssl: true, // verify the server certificate
});

test.afterAll(async () => {
  await pool.end();
});

test.describe('database read health check', () => {
  test('users table returns expected columns', async () => {
    // Execute a simple SELECT query
    const result = await pool.query('SELECT id, email FROM users LIMIT 1');
    
    // Verify we got results and the schema matches expectations
    expect(result.rowCount).toBeGreaterThan(0);
    expect(result.rows[0]).toHaveProperty('email');
  });
});
```

<Callout type="warn">
For databases reachable over a public network, keep `ssl: true` so the connection is encrypted and the certificate is verified. For a private CA use `ssl: { ca: getSecret('DB_CA_CERT') }`. Never set `rejectUnauthorized: false`.
</Callout>

## Reference

| Type | Databases |
|------|-----------|
| **Relational** | PostgreSQL, MySQL, SQL Server, MariaDB |
| **Cloud** | Amazon RDS, Azure SQL, Google Cloud SQL |

Connect directly to a publicly reachable database. Test runs cannot reach private-network addresses and there is no built-in SSH tunnel, so expose the database on a public address you restrict.
