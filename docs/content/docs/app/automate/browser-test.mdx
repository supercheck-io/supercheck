Automate user interactions with Playwright. Navigate pages, fill forms, click buttons, and validate content. Browser tests run in isolated containers on Chromium by default. Add `@firefox`, `@webkit` (or `@safari`) or `@mobile` to a test title to run it on that browser or device instead.

## Example

```typescript
import { expect, test } from '@playwright/test';

const APP_URL = 'https://the-internet.herokuapp.com';
const CREDENTIALS = { username: 'tomsmith', password: 'SuperSecretPassword!' };

test.describe('authentication flow', () => {
  test('user can sign in and sign out', async ({ page }) => {
    await page.goto(APP_URL + '/login');

    // Fill login form
    await page.getByLabel('Username').fill(CREDENTIALS.username);
    await page.getByLabel('Password').fill(CREDENTIALS.password);
    await page.getByRole('button', { name: 'Login' }).click();

    // Verify successful login
    await expect(page.getByText('You logged into a secure area!')).toBeVisible();
    
    // Perform logout
    await page.getByRole('link', { name: 'Logout' }).click();
    
    // Verify redirect to login page
    await expect(page).toHaveURL(APP_URL + '/login');
  });
});
```

## Common Actions

| Action | Code |
|--------|------|
| Navigate | `await page.goto('url')` |
| Click | `await page.getByRole('button', { name: 'Submit' }).click()` |
| Fill input | `await page.getByLabel('Email').fill('user@example.com')` |
| Check text | `await expect(page.locator('selector')).toHaveText('text')` |
| Wait | `await page.waitForSelector('selector')` |
| Screenshot | `await page.screenshot({ path: 'file.png' })` |

<Accordions>
<Accordion title="Selectors, assertions, and tips" id="selectors-tips">

**Selectors**

Use stable selectors:

```typescript
// Prefer accessible roles or stable test IDs.
await page.getByRole('button', { name: 'Submit' }).click();
await page.getByTestId('submit-btn').click();

// Avoid - class names change
await page.click('.btn-primary');
```

**Assertions**

```typescript
// URL
await expect(page).toHaveURL(/\/dashboard$/);

// Text visible
await expect(page.locator('.message')).toBeVisible();

// Text content
await expect(page.locator('h1')).toHaveText('Welcome');
```

**Tips**

- Use `data-testid` attributes for stable selectors
- Playwright auto-waits for elements
- Avoid fixed `waitForTimeout()` calls
- Take screenshots on failure for debugging
- Use `getSecret()` for passwords and API keys
