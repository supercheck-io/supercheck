Open **Respond → Copilot** to ask about your services, errors, or logs. From an incident, select **Ask Copilot** to bring its saved evidence into the same chat screen.

<Callout type="info">
Copilot is read-only. It gathers evidence and suggests checks, but cannot change your systems or apply a fix.
</Callout>

## Chat Modes


<Cards className="grid-cols-1 sm:grid-cols-2">
<Card icon={<MessageSquare className="text-blue-500" />} title="General chat">
Name the service you want to check. Copilot finds available sources in your current project and asks if the service is unclear. Connector results are temporary and are not added to incident evidence
</Card>
<Card icon={<Siren className="text-red-500" />} title="Incident chat">
Uses the incident's saved evidence, similar past incidents, and the connectors for its linked service. Starts with three suggested questions, and answers cite the evidence they rely on. **New chat** keeps the incident context. Results are saved on the incident
</Card>
</Cards>

## Live Sources

When **Live sources** is on, Copilot can query configured [connectors](/docs/app/investigate/connectors) for fresh data. Turn it off to use conversation text and saved evidence only.

If live data is unavailable, check the service and connector configuration in **Services**. A failed or incomplete query is an evidence gap, not a verified result.

## Conversations

| Control | What it does |
|---|---|
| **New chat** | Starts a fresh thread. To leave an incident context, open **Respond → Copilot** |
| **History** | Searches and restores your saved general and incident chats |
| **Archive** | Removes a chat from active history after you confirm. An archived chat cannot be continued; start a new chat |
| **Chat help** | Shows suggested questions and explains available sources |

History is private to you within your current organization and project. Let a response finish to keep its answer. A stopped answer is not saved. **Regenerate** replaces the previous reply, so only the new one is kept after a reload.

<Accordions>
<Accordion title="Asking useful questions and limits" id="questions-and-limits">
Ask one focused question, then review citations and any evidence gaps before acting.

- "Is checkout-api healthy? Check recent errors and latency."
- "Which evidence supports the leading hypothesis?"
- "What should I check next to confirm this?"
- "What changed before this started?" (incident chat)
- "Have we seen this before?" (incident chat; past incidents may be unrelated)

| Limit | Value |
|---|---|
| **Message length** | 4,000 characters, applied to the newest message only. Earlier replies in the chat can be longer |
| **Conversation length** | Long chats keep working. If a request would exceed Copilot's prompt budget, the oldest turns are left out of what it reads. A request body over about 2 MB is rejected with *Copilot chat history is too large* |
| **Rate** | 30 messages per minute per person |
| **Images, videos and files** | File upload is not supported, and Copilot does not open or inspect file contents. The chat API still accepts a file attachment that references storage scoped to the same incident, but only its metadata reaches the model. Paste relevant text instead |

Answers can include markdown tables and small bar, line or area charts (up to 4 series and 48 points). Charts use only values from evidence, tool results or your messages; a chart without numeric values is shown as raw data instead.

Keep credentials in connector settings, not in chat.

For a full investigation with a saved report, use [Incident Investigation](/docs/app/investigate/incidents).

</Accordion>

<Callout type="warn">
On Supercheck Cloud, Copilot replies, incident triage, and evidence brief generation require an active organization subscription and a valid billing customer. If access is blocked, open **Settings → Organization → Subscription**. Self-hosted installations do not use these billing checks. Investigation runs also enforce spending limits.

The free trial includes AI triage runs and investigations (see [Incident Investigation](/docs/app/investigate/incidents#trial-allowance)). Copilot chat and evidence briefs need a paid plan, and the Copilot screen says so instead of showing the chat.
</Callout>
