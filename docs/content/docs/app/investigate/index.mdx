## Read-Only By Design

Supercheck recommends checks and fixes; it does not modify your infrastructure. Opening an incident does not start an investigation. Select **Run investigation** when you are ready.

## Native Evidence

Supercheck uses stored summaries and artifact references from its tests, monitors, runs, and status pages:

- Failed monitor screenshots and Playwright videos
- Console logs and network traces from synthetic tests
- Historical monitor results with P50/P95/P99 latency trends
- Run logs and step artifacts
- Public and private status page states

Responders can inspect available screenshots, videos, and other artifacts through their source runs and monitors. The agent reads bounded text evidence and artifact references; it does not watch videos or automatically analyze screenshot contents.

## Core Navigation

| Screen | Purpose |
|---|---|
| **Communicate → Alerts** | Grouped failure signals, notification history, and channels. Select **Investigate** to open an incident directly. |
| **Investigate → [Incidents](/docs/app/investigate/incidents)** | Incident queue and detail workspaces. Run AI investigations and generate shareable evidence briefs. |
| **Investigate → [Copilot](/docs/app/investigate/copilot)** | Interactive AI assistant for asking questions about symptoms, logs, or active incident evidence. |
| **Investigate → Services** | Manage service metadata, ownership teams, repositories, and tier classifications. |
| **Organization Admin → [Integrations](/docs/app/investigate/connectors)** | Configure read-only integrations for GitHub, Kubernetes, Prometheus, Grafana, Datadog, and Loki. |

## Get Started

Select **Investigate** on an alert signal, or choose **Investigate → Incidents → New incident**. Follow the [incident guide](/docs/app/investigate/incidents) to investigate, save findings, and resolve. Services and live connectors are optional for stored-evidence investigations.
