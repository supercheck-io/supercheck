Supercheck's AI SRE transforms existing tests, monitors, jobs, alert history, and status pages into an automated, **read-only incident investigation loop**. It connects to your existing operational tools, gathers scoped evidence, explains what likely happened with citations, and recommends fix and recovery-check steps for a human responder.

## Read-Only By Design

**Supercheck's AI SRE layer is explicitly read-only.** It never writes to your production systems or executes remediation actions on your behalf.

- The agent gathers evidence, correlates data, reasons, and recommends.
- You apply fixes in your own systems using your own tools and safeguards.
- You use existing Playwright tests, k6 performance tests, or synthetic monitors to confirm recovery after applying the fix.

## Native Evidence

Supercheck uses stored summaries and artifact references from its tests, monitors, runs, and status pages:

- Failed monitor screenshots and Playwright videos
- Console logs and network traces from synthetic tests
- Historical monitor results with P50/P95/P99 latency trends
- Run logs and step artifacts
- Public and private status page states

Responders can inspect available screenshots, videos, and other artifacts through their source runs and monitors. The agent reads bounded text evidence and artifact references; it does not watch videos or automatically analyze screenshot contents.

| **Investigate → [Incidents](/docs/app/investigate/incidents)** | Incident queue and detail workspaces. Run AI investigations and generate shareable evidence briefs. |
| **Investigate → [Copilot](/docs/app/investigate/copilot)** | Interactive AI assistant for asking questions about symptoms, logs, or active incident evidence. |

## Start with an Incident

1. Open **Communicate → Alerts → Signals** and select **Investigate** next to a failure, or create an incident from **Investigate → Incidents → New incident**.
2. Review the incident's **Overview**. Collect evidence if needed, then explicitly select **Run investigation**.
3. Review the cited findings. Apply a fix with your own tools and confirm recovery with your tests or monitors.
4. Select **Resolve incident** and record what confirmed recovery.

Opening an incident does not start a full AI investigation. Services, live sources, and the map are optional; you can investigate stored evidence without setting them up.
