## Requirements

| Requirement | Minimum |
|-------------|---------|
| Docker Engine | 20.10+ |
| Docker Compose | v2.24.4+ (`docker compose`) |
| OS | Linux (Ubuntu 22.04+, Debian 12+) |
| Architecture | x86_64 or arm64 |
| CPU | 2 vCPU minimum, 4 vCPU recommended |
| Memory | 4GB minimum, 8GB recommended |
| Storage | 15GB free minimum, 30–50GB recommended |
| Domain | Optional (required for HTTPS) |

<Callout type="warn">
**Linux only** — Supercheck's test-execution sandbox requires the Linux kernel. macOS and Windows are not supported, including Docker Desktop and WSL2.
</Callout>

The guided installer installs Docker, Compose, and other prerequisites automatically. See [Self-Hosted](/docs/app/deployment/self-hosted) to get started.

## Services

| Service | Purpose |
|---------|---------|
| **app** | Next.js frontend and API |
| **worker** | Test execution (Playwright/K6) |
| **postgres** | Database |
| **redis** | Job queues |
| **rustfs** | Artifact storage (S3-compatible) |
| **traefik** | HTTPS reverse proxy (production only) |
