## Quickstart

<Steps>
<Step>

### Open a workspace

[Self-host](/docs/app/deployment/self-hosted) with Docker Compose, or use Supercheck Cloud. On Cloud, create your account with GitHub, Google or an invitation link and verify your email. Then choose a plan on the subscribe page; eligible new accounts can start a free trial with no card. See [Pricing](/pricing).

</Step>
<Step>

### Create a test

Write one in the [Playground](/docs/app/automate/playground), or record it with the [Recorder](/docs/recorder).

</Step>
<Step>

### Run it on a schedule

Add the test to a [job](/docs/app/automate/jobs) with a cron schedule. To keep checking production, attach a Playwright test to a [synthetic monitor](/docs/app/monitor#synthetic-monitor). Add HTTP, website, ping, port or MCP monitors for uptime.

</Step>
<Step>

### Get alerted

Add a [notification channel](/docs/app/communicate/alerts) and select it on your monitors and jobs.

</Step>
<Step>

### Tell your users

Publish a [status page](/docs/app/communicate/status-pages) and link monitors to its components.

</Step>
</Steps>

To manage this as code, start with the [CLI](/docs/cli).
