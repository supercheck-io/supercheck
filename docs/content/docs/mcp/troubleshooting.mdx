---
title: Troubleshooting
description: Fix common problems connecting an AI tool to Supercheck
icon: LifeBuoy
---

<Accordions>
<Accordion title="The browser never opens" id="mcp-t1">

Run the tool's auth command (for example `/mcp` in Claude Code) and choose **supercheck**. Check the URL ends in `/api/mcp`

</Accordion>
<Accordion title="401 after working earlier" id="mcp-t2">

The token expired and could not refresh. Sign in again from the client, or reconnect

</Accordion>
<Accordion title="403 access_denied" id="mcp-t3">

Access was removed. If the app was disconnected, reconnect and approve again. If you were removed from the organization or your account is banned, ask an admin; access returns once it is restored, with no reconnect needed

</Accordion>
<Accordion title="429 rate_limited or too_many_concurrent_requests" id="mcp-t4">

One app may send up to 300 requests a minute and 4 at a time; all your apps together 600 a minute and 8 at a time. Wait for the `Retry-After` seconds, or send fewer calls at once

</Accordion>
<Accordion title="503 rate_limiter_unavailable" id="mcp-t5">

The server's rate limiter is temporarily unavailable, so the call was refused rather than let through unchecked. Retry after the `Retry-After` seconds. An administrator should check that Redis is reachable

</Accordion>
<Accordion title="400 batch_too_large" id="mcp-t6">

A single request may carry at most 20 calls. Split larger batches

</Accordion>
<Accordion title="Project missing on the approval screen" id="mcp-t7">

You can only share projects you can access. Ask an owner to add you

</Accordion>
<Accordion title="forbidden from a tool" id="mcp-t8">

Your role cannot view that resource type. Ask for a role that can

</Accordion>
<Accordion title="Stdio-only client" id="mcp-t9">

Bridge with `npx mcp-remote https://your-supercheck-host/api/mcp`

</Accordion>
<Accordion title="Self-hosted: 404 not_found from /api/mcp" id="mcp-t10">

MCP is off on this server. A self-hosting admin must set `MCP_SERVER_ENABLED=true` and recreate the app

</Accordion>
<Accordion title="Self-hosted: crash on start with a BETTER_AUTH_URL error" id="mcp-t11">

`BETTER_AUTH_URL` must be the public HTTPS URL (`http://localhost:3000` is accepted for local use). The Docker setup derives it from `APP_DOMAIN`

</Accordion>
<Accordion title="Self-hosted: calls fail behind a proxy" id="mcp-t12">

Make sure the proxy passes the `Authorization` header through to `/api/mcp`

</Accordion>
</Accordions>

To inspect the server directly, run `npx @modelcontextprotocol/inspector` and connect to `https://your-supercheck-host/api/mcp` with the Streamable HTTP transport.
