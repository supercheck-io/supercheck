Sends a test through a saved channel using its stored configuration. Webhook channels (including paging presets) receive a test page with dedup key `test:<id>`; `action: resolve` closes it (Opsgenie and Jira Service Management by alias). Requires notification update permission. Rate limited per user (20 per 10 minutes; email 5).
