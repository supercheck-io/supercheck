Sends a test through a saved channel using its stored configuration. Webhook channels (including paging presets) receive a test page with dedup key `test:<id>`; `action: resolve` closes it on paging presets (Opsgenie and Jira Service Management by alias); a custom webhook receives the same template with the resolve action and dedup key, and closes the page only if the receiver uses them. `resolve` is rejected for non-webhook channels. Requires notification update permission. Rate limited per user (20 per 10 minutes; email 5).
