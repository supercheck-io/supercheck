The supported public Supercheck API provides programmatic access to jobs, tests, monitors, variables, notifications, and other documented resources. The web dashboard also uses internal and streaming routes that are intentionally outside this public API contract.

## Base URL

| Environment | URL |
|-------------|-----|
| **Cloud** | `https://app.supercheck.io` |
| **Self-Hosted** | Your deployment URL (e.g. `https://supercheck.yourdomain.com`) |

## Authentication

Resource-management requests require authentication via an `Authorization: Bearer <token>` header. Explicitly public endpoints, such as health checks and published status-page feeds, do not. See [Authentication](./authentication) for details on token types.

```bash
curl https://app.supercheck.io/api/jobs \
  -H "Authorization: Bearer sck_live_..."
```

## OpenAPI Specification

The OpenAPI 3.1 specification for the supported public API is available for SDK generation and tooling:

| Format | URL |
|--------|-----|
| **JSON** | `/openapi/openapi.json` |
| **YAML** | `/openapi/openapi.yaml` |

### SDK Generation

```bash
# TypeScript types
npx openapi-typescript https://app.supercheck.io/openapi.json -o ./types/supercheck-api.d.ts

# TypeScript client
npx openapi-typescript-codegen \
  --input https://app.supercheck.io/openapi.json \
  --output ./sdk

# Python
openapi-generator generate \
  -i https://app.supercheck.io/openapi.json \
  -g python -o ./supercheck-sdk-python

# Go
openapi-generator generate \
  -i https://app.supercheck.io/openapi.json \
  -g go -o ./supercheck-sdk-go
```

## Response Format

All responses are JSON. Paginated endpoints return:

```json
{
  "data": [...],
  "pagination": {
    "total": 42,
    "page": 1,
    "limit": 50,
    "totalPages": 1,
    "hasNextPage": false,
    "hasPrevPage": false
  }
}
```

## Rate Limits

| Token Type | Limit | Window |
|------------|-------|--------|
| CLI Token (`sck_live_*`) | 1000 req/min | Per user |
| Trigger Key (`sck_trigger_*`) | 60 req/min | Per key |
| Unauthenticated | 10 req/min | Per IP |

Rate limit headers are included in every response:

```
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 1612137600
Retry-After: 60  # Only on 429 responses
```
