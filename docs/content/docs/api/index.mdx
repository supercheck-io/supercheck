The public API gives programmatic access to jobs, tests, monitors, variables, notifications and other documented resources. Internal and streaming dashboard routes are outside this contract.

## Base URL

| Environment | URL |
|-------------|-----|
| **Cloud** | `https://app.supercheck.io` |
| **Self-hosted** | Your deployment URL (e.g. `https://supercheck.yourdomain.com`) |

## Authentication

Resource requests need an `Authorization: Bearer <token>` header. Public endpoints, such as health checks and published status-page feeds, do not. See [Authentication](/docs/api/authentication).

```bash
curl https://app.supercheck.io/api/jobs \
  -H "Authorization: Bearer sck_live_..."
```

## OpenAPI specification

The OpenAPI 3.1 spec is available for SDK generation:

| Format | URL |
|--------|-----|
| **JSON** | `/openapi/openapi.json` |
| **YAML** | `/openapi/openapi.yaml` |

### SDK generation

```bash
# TypeScript types
npx openapi-typescript https://supercheck.io/openapi/openapi.json -o ./types/supercheck-api.d.ts

# TypeScript client
npx openapi-typescript-codegen \
  --input https://supercheck.io/openapi/openapi.json \
  --output ./sdk

# Python
openapi-generator generate \
  -i https://supercheck.io/openapi/openapi.json \
  -g python -o ./supercheck-sdk-python

# Go
openapi-generator generate \
  -i https://supercheck.io/openapi/openapi.json \
  -g go -o ./supercheck-sdk-go
```

## Response format

Responses are JSON. Pagination is endpoint-specific; resource lists commonly return:

```json
{
  "data": [],
  "pagination": {
    "total": 0,
    "page": 1,
    "limit": 50,
    "totalPages": 0,
    "hasNextPage": false,
    "hasPrevPage": false
  }
}
```

## Rate limits

Trigger keys default to 100 requests per 60 seconds, configurable per key. Other endpoints have their own limits. See [Authentication](/docs/api/authentication#rate-limiting).
