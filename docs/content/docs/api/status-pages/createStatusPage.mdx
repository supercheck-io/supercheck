Create a status page in the current project. Requires `status_page:create`. The page starts as a `draft` and its `subdomain` is generated by the server; sending `subdomain` or `customDomainVerified` returns 400. Unknown body fields are rejected. If your account allows it, creation succeeds; otherwise a 403 explains the limit that was reached. A 429 means too many concurrent create requests - retry shortly.
