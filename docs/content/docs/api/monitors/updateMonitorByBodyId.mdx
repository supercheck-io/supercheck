Compatibility update that requires `id` in the JSON body. Prefer `PATCH /api/monitors/{id}` or `PUT /api/monitors/{id}` for new integrations. The monitor must belong to the current project. `alertConfig` is applied only when the body has the key: omit it to leave alert settings and linked channels untouched, send `null` to clear both. The caller needs the same `monitor:update` permission as `PUT /api/monitors/{id}`, checked before the monitor is looked up.
