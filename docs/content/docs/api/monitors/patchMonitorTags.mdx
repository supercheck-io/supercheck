Atomically add and/or remove individual tags without replacing the whole set, so concurrent changes are not lost. Requires `monitor:update`. Removed tags are applied first; adding an already-assigned tag or removing an unassigned tag is a no-op. Added tags must exist in the current project and the result may hold at most 10 tags (400 otherwise). The same tag cannot be in both lists.
