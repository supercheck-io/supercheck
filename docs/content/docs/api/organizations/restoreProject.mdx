Organization owners and admins. Undoes a project deletion within its 7 day restore window. Monitors and status pages beyond the plan limits stay paused or archived. Returns 409 with code RESTORE_WINDOW_ENDED once the window is over, or PURGE_STARTED while the project is being purged; 403 with code ORG_PENDING_DELETION while the organization is pending deletion, or PLAN_LIMIT when the plan has no room for another project. Not allowed while impersonating. Requires an interactive, same-origin browser session.
