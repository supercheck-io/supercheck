Leave the active organization as a non-owner using an interactive browser session and a same-origin request. Removes the caller's membership and project assignments, clears this organization's selected context from all their sessions, and records member_left in the audit log. Owners must transfer ownership or delete the organization. Project-scoped CLI tokens receive 403. The supplied organization ID must match the active organization resolved from the session; stale confirmations receive 409.
