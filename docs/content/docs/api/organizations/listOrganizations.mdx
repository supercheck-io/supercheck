Returns the selected project's host organization, or the default account organization when no project is selected. Users cannot create or switch organizations directly; they can select projects from their account and invited teams. The existing list response is preserved for compatibility: data contains zero or one organization and activeOrganizationId identifies that organization; it is not a directory of all team memberships.
