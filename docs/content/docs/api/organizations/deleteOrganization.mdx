Owner only. Schedules the organization for deletion. The organization becomes read-only for a grace window (14 days by default, ORG_DELETION_GRACE_DAYS on self-hosted installations) during which the owner can cancel. A self-hosted installation with ORG_DELETION_GRACE_DAYS=0 has no window: the purge is queued at once and the deletion cannot be cancelled. A subscription stops renewing and ends at the end of the paid period, and the owners are emailed when mail is configured. After the window the projects, data and stored files are deleted permanently. Audit log entries are kept for 12 months with email addresses removed. The body must repeat the organization name in confirmName. Needs a session created within the last few minutes (403 with code REAUTH_REQUIRED otherwise). Not allowed while impersonating. Requires an interactive, same-origin browser session; project-scoped CLI tokens receive 403.
