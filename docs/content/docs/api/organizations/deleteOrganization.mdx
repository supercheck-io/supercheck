Owner only. Deletes the organization and everything in it: every project, its data and stored files, and member access. An active subscription is cancelled. This cannot be undone. The request body must name the organization in confirmOrganizationId. Not allowed from an impersonated session. Rate limited to 5 attempts per 10 minutes. Selected browser session references are cleared atomically. Browser mutations require a same-origin request; CLI tokens retain their existing authorization. Requires an interactive browser session. Project-scoped CLI tokens receive 403.
