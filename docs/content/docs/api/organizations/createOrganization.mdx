Requires a same-origin browser session; CLI tokens are not supported. Creates an organization, owner membership, and default project, then selects them in the session. Cloud creation requires a verified email and starts without a subscription; plans and billing customers are not inherited. The default cloud ownership cap is five organizations per user (configurable by the operator). Self-hosted organizations require no cloud subscription.
