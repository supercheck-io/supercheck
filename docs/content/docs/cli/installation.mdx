---
title: Installation
description: Install and set up the Supercheck CLI
---

Requires **Node.js 20** or later.

<Steps>
<Step>

### Install

```bash
# Global install (recommended)
npm install -g @supercheck/cli

# Or run without installing
npx @supercheck/cli health
```

</Step>
<Step>

### Verify

```bash
supercheck --version
supercheck health
```

</Step>
<Step>

### Sign in

```bash
supercheck login
```

Approve the code in your browser. To use a token instead, create one under **Settings → Organization → CLI Tokens → Create Token** (shown only once) and pass it:

```bash
supercheck login --token sck_live_a1b2c3d4...
```

In CI/CD no login step is needed. Export the token and the CLI reads it at runtime:

```bash
export SUPERCHECK_TOKEN="sck_live_..."
```

</Step>
<Step>

### Initialize a project

```bash
supercheck init
```

</Step>
</Steps>

<Callout type="info">
`supercheck job trigger` uses `SUPERCHECK_TRIGGER_KEY`, not the CLI token. Add `SUPERCHECK_TOKEN` only when you also use `--wait` or other API commands.
</Callout>

Local test execution does not require a Supercheck account: `supercheck test run --offline --file <path>` or `supercheck job run --id <name-or-id> --local --offline` use local Playwright/k6 dependencies and skip server validation. Cloud commands still require credentials. For agent setup, see [Agent Quickstart](/docs/cli/agent-quickstart).

## What `init` Creates

```
my-project/
├── _supercheck_/
│   ├── playwright/   # Playwright test files
│   └── k6/           # k6 performance tests
└── supercheck.config.ts
```

`init` also installs `@playwright/test` and `@types/k6` as dev dependencies, downloads the Playwright **chromium** browser for local execution, and warns if **k6** is not installed (needed for performance tests).

## Test Dependencies

| Dependency | Needed for | Install |
|---|---|---|
| `@playwright/test` and chromium | Browser and API tests | Handled by `supercheck init`, or `npm install --save-dev @playwright/test && npx playwright install chromium` |
| k6 | Performance tests | macOS `brew install k6`; Linux `sudo snap install k6`; Windows `choco install k6` or `winget install k6` ([more options](https://grafana.com/docs/k6/latest/set-up/install-k6/)) |

Check everything with `supercheck doctor`.

## Docker

Set `SUPERCHECK_JOB_ID` and both tokens in your environment, then run the CLI using the official Node.js image:

```bash
docker run --rm \
  -e SUPERCHECK_TRIGGER_KEY -e SUPERCHECK_TOKEN -e SUPERCHECK_JOB_ID \
  node:20-slim sh -c 'npm install -g @supercheck/cli && supercheck job trigger "$SUPERCHECK_JOB_ID" --wait'
```

See [CI/CD Integration](./ci-cd) for Docker-based pipeline examples.

<Accordions>
<Accordion title="Self-hosted" id="self-hosted-setup">

Point the CLI at your instance's HTTPS URL. Cloud users do not need this: the default is `https://app.supercheck.io`.

```bash
export SUPERCHECK_URL="https://supercheck.yourdomain.com"
export SUPERCHECK_TOKEN="sck_live_..."

supercheck login --token $SUPERCHECK_TOKEN --url $SUPERCHECK_URL
supercheck health
```

See the [production deployment guide](/docs/app/deployment/self-hosted) if your administrator still needs to configure HTTPS.

</Accordion>
<Accordion title="Proxy configuration" id="proxy-configuration">

The CLI respects standard proxy environment variables:

```bash
export HTTPS_PROXY="http://proxy.corp.com:8080"
export NO_PROXY="localhost,127.0.0.1,.internal.corp.com"
export SUPERCHECK_TRIGGER_KEY="sck_trigger_..."
export SUPERCHECK_TOKEN="sck_live_..."
supercheck job trigger <id> --wait
```

</Accordion>
<Accordion title="Manual Playwright and k6 setup" id="test-dependencies">

If you skip `supercheck init`:

```bash
npm install --save-dev @playwright/test
npx playwright install chromium
```

Run `supercheck doctor` to verify dependencies.

</Accordion>
<Accordion title="Uninstall" id="uninstall">

```bash
# Clear stored credentials first
supercheck logout

# Remove global install
npm uninstall -g @supercheck/cli
```

</Accordion>
</Accordions>
