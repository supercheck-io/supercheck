========================================================================
Welcome to the Supercheck Dev Container!
========================================================================

1. Environment setup:
   cp app/.env.example app/.env
   cp worker/.env.example worker/.env

2. Start background services (PostgreSQL, Redis, MinIO):
   docker compose -f deploy/docker/docker-compose-local.yml up -d postgres redis minio

3. Run the applications in VS Code terminals:
   - App: cd app && npm run dev
   - Worker: cd worker && npm run dev

4. Run tests:
   - App unit tests: cd app && npm test
   - App e2e tests: cd app && npm run e2e
   - Worker unit tests: cd worker && npm test

Note:
Do not modify or commit .env files with secrets!
If you change `.devcontainer/devcontainer.json` or `Dockerfile`, you will need to rebuild the container via VS Code: "Dev Containers: Rebuild Container".
========================================================================
